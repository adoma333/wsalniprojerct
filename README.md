# وصلني — Wasalni 🚗

منصة نقل متكاملة للجزائر: **تطبيق للزبون** و**تطبيق للسائق** (أندرويد APK + ويب للآيفون)، **لوحة تحكم** ويب متجاوبة، و**صفحة هبوط** ديناميكية — بنفس الهوية البصرية.
الميزة الأساسية: **اركب مجانًا** بجمع النقاط من مشاهدة الإعلانات — كل إعلان مكتمل = **100 نقطة**، و100 نقطة = **5 دج** (قيمة يغيّرها المدير في أي وقت دون أن يلاحظ الزبون، فهو يرى النقاط فقط). تحويل يدوي أو تلقائي للنقاط إلى رصيد البورتفاي.

ميزات أخرى: خريطة احترافية (نمط مخصص، 3D، قمر صناعي، ليلية، لوحة قابلة للسحب، تحديد الانطلاق والوصول بالدبوس)، شحن الرصيد بالبطاقة الذهبية / CIB / بريدي موب / القسائم، **خصم الطلبة** بتصوير بطاقة الطالب بماسح كاميرا احترافي (كشف وتفعيل فوري)، توثيق وثائق السائقين بنفس الماسح، **اقترح سومتك**، كود PIN للرحلة، **رحلة لشخص آخر** (بلا كود، مع رسالة واتساب وصفحة تتبّع مباشر بلا تطبيق)، طلب سائقة امرأة، تفضيلات الكورسة.
**تتبّع الحافلات**: خريطة الخطوط والمحطات والحافلات (مباشرة من سائقي الحافلات أو تقديرية حسب جدول الخط) مع أقرب محطة ووقت المشي ووقت وصول كل حافلة. **نوافذ إشعار بالشاشة كاملة** (صورة/فيديو/عنوان/نص/رابط) من لوحة التحكم.
السائق: **بورتفاي خاص** (شحن بالبطاقة، سحب الأرباح لـ CCP/بريدي موب/بنك، حد أدنى للرصيد)، تحديات يومية بمكافآت، فلتر الطلبات.

```
صفحة الهبوط  /          ─┐
تطبيق الزبون  /app/      ─┤  surge.sh (استضافة مجانية)        ┌─ خادم وصلني على الـVPS: Node.js + SQLite + HTTPS (Caddy)
تطبيق السائق  /driver/   ─┼─────────────────────────────────────┤   كل الهواتف واللوحة متصلة لحظيًا (SSE)
لوحة التحكم   /admin/    ─┤                                     └─ بدونه: وضع العرض (تخزين محلي + أسطول محاكاة)
ملفات APK     /downloads/ ┘
GitHub Actions: بناء الويب ← APK (زبون + سائق) ← نشر surge ← إرسال الروابط والملفات لبوت تلجرام
```

## التشغيل: أمر واحد على السيرفر

أمر واحد يجهّز كل شيء: يحفظ الأسرار في GitHub، **يثبّت خادم قاعدة البيانات (SQLite) مع HTTPS تلقائي**، ويشغّل البناء:

```bash
bash <(curl -fsSL https://raw.githubusercontent.com/adoma333/wsalniprojerct/HEAD/setup/setup.sh)
```

يسألك عن:
1. **توكن GitHub** (Fine-grained لهذا المستودع: Secrets + Actions قراءة/كتابة، Contents قراءة).
2. **توكن بوت تلجرام** ← ثم ترسل `/start` للبوت فيجلب **Chat ID تلقائيًا**.
3. **بريد وكلمة سر surge.sh** (يُنشأ الحساب تلقائيًا إن لم يوجد) ← ويقترح رابطًا مثل `wasalni-xxxx.surge.sh`.
4. يولّد **مفتاح توقيع دائم** لملفات APK (ونسخة احتياطية تصلك على تلجرام).
5. يثبّت **خادم قاعدة البيانات** (`server/server.mjs`، بلا مكتبات): خدمة systemd + Caddy بشهادة HTTPS على `‹IP›.sslip.io` (يحتاج المنفذين 80/443)، وإلا نفق Cloudflare مجاني تلقائيًا. نسخة احتياطية يومية تصلك على تلجرام. الخادم **يتحدّث وحدو** كل 6 ساعات من الموقع المنشور (`/srv/`)، فما تحتاجش تعاود الأمر بعد كل تحديث.

بعد 10–15 دقيقة تصلك على تلجرام: روابط الموقع + لوحة التحكم + ملفّا APK.
إعادة تشغيل الأمر آمنة (الإعدادات محفوظة في `/etc/wasalni/setup.env`).

## الهيكل

| المسار | المحتوى |
|---|---|
| `apps/{landing,rider,driver,admin}` | نقاط الدخول (HTML + main) |
| `server/server.mjs` | خادم قاعدة البيانات المشتركة (SQLite + SSE + قواعد الأمان) |
| `src/core/` | طبقة البيانات (`store-remote` للخادم / `store-local` / `store-firebase`)، المنطق (`api.js`)، التسعير، الخرائط والمسارات، الريلز، أسطول المحاكاة |
| `src/ui/` | نظام التصميم والمكونات المشتركة |
| `src/rider/` `src/driver/` `src/admin/` `src/landing/` | الشاشات |
| `firebase/firestore.rules` | قواعد الأمان |
| `setup/setup.sh` | أمر الإعداد الواحد |
| `.github/workflows/build.yml` | البناء والنشر والإرسال لتلجرام |
| `docs/HANDOFF.md` | قرارات المشروع وما يلزم معرفته |
