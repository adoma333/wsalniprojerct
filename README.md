# وصلني — Wasalni 🚗

منصة نقل متكاملة للجزائر: **تطبيق للزبون** و**تطبيق للسائق** (أندرويد APK + ويب للآيفون)، **لوحة تحكم** ويب متجاوبة، و**صفحة هبوط** ديناميكية — بنفس الهوية البصرية.
الميزة الأساسية: **اركب مجانًا** بجمع النقاط من مشاهدة الريلز الإعلانية — كل ريل مكتمل = **5 دينار** في رصيد المكافآت.

```
صفحة الهبوط  /          ─┐
تطبيق الزبون  /app/      ─┤  surge.sh (استضافة مجانية)        ┌─ Firebase (Firestore + Auth) — اختياري
تطبيق السائق  /driver/   ─┼─────────────────────────────────────┤
لوحة التحكم   /admin/    ─┤                                     └─ بدونه: وضع العرض (تخزين محلي + أسطول محاكاة)
ملفات APK     /downloads/ ┘
GitHub Actions: بناء الويب ← APK (زبون + سائق) ← نشر surge ← إرسال الروابط والملفات لبوت تلجرام
```

## التشغيل: أمر واحد على السيرفر

السيرفر **لا يشغّل أي خدمة** — الأمر فقط يجمع المعلومات ويحفظها كأسرار في GitHub ثم يشغّل البناء:

```bash
bash <(curl -fsSL https://raw.githubusercontent.com/adoma333/wsalniprojerct/HEAD/setup/setup.sh)
```

يسألك عن:
1. **توكن GitHub** (Fine-grained لهذا المستودع: Secrets + Actions قراءة/كتابة، Contents قراءة).
2. **توكن بوت تلجرام** ← ثم ترسل `/start` للبوت فيجلب **Chat ID تلقائيًا**.
3. **بريد وكلمة سر surge.sh** (يُنشأ الحساب تلقائيًا إن لم يوجد) ← ويقترح رابطًا مثل `wasalni-xxxx.surge.sh`.
4. يولّد **مفتاح توقيع دائم** لملفات APK (ونسخة احتياطية تصلك على تلجرام).
5. **Firebase** (اختياري) لربط كل الأجهزة ببعض لحظيًا.

بعد 10–15 دقيقة تصلك على تلجرام: روابط الموقع + لوحة التحكم + ملفّا APK.
إعادة تشغيل الأمر آمنة (الإعدادات محفوظة في `/etc/wasalni/setup.env`).

## لوحة التحكم

`https://<الرابط>/admin/` — المدير: **contwais@gmail.com**.
**عند أول فتح** تطلب منك اختيار كلمة السر وتُحفظ للأبد (في Firebase Auth، أو في المتصفح بوضع العرض)، وبعدها تُطلب عند كل دخول. يمكن تغييرها من الإعدادات.
> افتح اللوحة مباشرة بعد أول نشر لتثبيت كلمة السر قبل أي شخص آخر.

تشمل: المؤشرات والرسوم، الخريطة الحية، الرحلات، موافقة السائقين ومستنداتهم، الزبائن وأرصدتهم، التسعير وحاسبة الأسعار، الريلز والإعلانات (صورة/فيديو)، إعدادات المكافآت، أكواد الخصم، قسائم الشحن، الإشعارات، الدعم والطوارئ، أسطول المحاكاة والقبول التلقائي.

## الهيكل

| المسار | المحتوى |
|---|---|
| `apps/{landing,rider,driver,admin}` | نقاط الدخول (HTML + main) |
| `src/core/` | طبقة البيانات (`store-local` / `store-firebase`)، المنطق (`api.js`)، التسعير، الخرائط والمسارات، الريلز، أسطول المحاكاة |
| `src/ui/` | نظام التصميم والمكونات المشتركة |
| `src/rider/` `src/driver/` `src/admin/` `src/landing/` | الشاشات |
| `firebase/firestore.rules` | قواعد الأمان |
| `setup/setup.sh` | أمر الإعداد الواحد |
| `.github/workflows/build.yml` | البناء والنشر والإرسال لتلجرام |
| `docs/HANDOFF.md` | قرارات المشروع وما يلزم معرفته |
